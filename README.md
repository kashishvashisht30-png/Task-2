
# New York City Airbnb Exploratory Data Analysis and Visualization

This project presents a comprehensive **Exploratory Data Analysis (EDA)** of the **New York City Airbnb Open Dataset** using Python and popular data analytics libraries. The objective of the project is to uncover meaningful insights, identify patterns, analyze relationships between variables, and visualize trends within Airbnb listings across New York City.

The analysis begins with data loading and preliminary exploration to understand the dataset structure, data types, and key attributes. Statistical summaries are generated to gain insights into important numerical features such as price, availability, minimum nights, and review counts. Various visualization techniques are then applied to explore the distribution of Airbnb listings, pricing behavior, room type preferences, neighborhood popularity, and host activity.

The project utilizes **Pandas** for data manipulation, **NumPy** for numerical operations, **Matplotlib** for data visualization, and **Seaborn** for advanced statistical graphics. Multiple visualizations including histograms, count plots, box plots, scatter plots, bar charts, pair plots, and correlation heatmaps are created to identify trends, anomalies, and relationships among different variables.

Key findings from the analysis reveal that Manhattan and Brooklyn dominate the Airbnb market, entire homes and apartments are the most preferred accommodation type, and listing prices exhibit a highly skewed distribution due to luxury properties. Correlation analysis further highlights relationships between reviews, availability, and pricing factors.

This project demonstrates practical skills in **data exploration, statistical analysis, data visualization, feature interpretation, and business insight generation**. The results provide valuable information for Airbnb hosts, travelers, and analysts interested in understanding short-term rental market trends. Additionally, the project serves as a strong foundation for future machine learning applications such as price prediction, demand forecasting, and customer behavior analysis.
